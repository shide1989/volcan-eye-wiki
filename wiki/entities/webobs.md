# WebObs

An open-source system for volcano-observatory monitoring that handles data import, processing, scheduling, alarm notification and web display. The [[jerk-signal]] detector runs in it as a "proc" module at [[ovpf-ipgp]]. According to the authors it was built "in only a few days" thanks to WebObs (p. 6). Code, including the Jerk module: https://ipgp.github.io/webobs. Source: [[jerk-beauducel-2025]] (pp. 6–7).
